# Security Policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for the published repository. Do not disclose exploitable scanner-command injection, path traversal, unsafe report handling, or credential exposure in a public issue before a fix is available.

Include the affected version, reproduction steps, impact, and a suggested mitigation when possible.

## Scope

This repository contains prompts, templates, configuration examples, and validation scripts. It does not bundle or replace security scanners. Scanner accuracy and vulnerability databases remain the responsibility of their respective tools.
